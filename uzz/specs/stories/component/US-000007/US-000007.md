# User Stories for Domain: component

## [US-000007] Handle Clipboard Updates
**As a** Developer,
**I want** to receive and send clipboard updates between the local and remote desktops,
**So that** users can copy and paste text seamlessly.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX clipboard API, TigerVNC library
* clipboard text received from remote is stored in a FX property "clipboard"

### Acceptance Criteria
```gherkin
Scenario: Receive Clipboard Updates from Server
  Given a VNCViewerFX component with an active connection
  When the VNC server sends a clipboard update
  Then the property "clipboard" contains the clipboard text

Scenario: Send Clipboard Updates to Server
  Given a VNCViewerFX component with an active connection
  When I update the property "clipboard"
  Then the text should be sent to the VNC server's clipboard (i.e. I can paste it in a remote application)
```
