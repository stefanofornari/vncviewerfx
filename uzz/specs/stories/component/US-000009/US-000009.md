# User Stories for Domain: component

## [US-000009] Support ZRLE Encoding
**As a** Developer,
**I want** to use ZRLE encoding for efficient compression of framebuffer updates,
**So that** the VNC viewer performs well even on slow connections.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: TigerVNC library, ZRLE encoding

### Acceptance Criteria
```gherkin
Scenario: Use ZRLE Encoding
  Given a VNCViewerFX component with an active connection
  When framebuff updates are exchanged
  Then framebuffer updates should be compressed using ZRLE encoding (checked in client or server logs)
```
