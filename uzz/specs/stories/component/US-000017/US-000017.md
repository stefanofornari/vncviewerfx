# User Stories for Domain: component

## [US-000017] Display Animated Disconnection Pane
**As a** Developer,
**I want** the VNCViewerFX component to display an animated disconnection pane
**So that** users see a clear visual indication with animated feedback when disconnected.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX UI feedback, FXML, JavaFX animations
* **Parent Story**: US-000010 (Handle Connection Loss Gracefully)
* **Dependencies**: The disconnection pane will be controlled by the `connected` BooleanProperty from VNCCanvas

### Acceptance Criteria
```gherkin
Scenario: Scramble animation starts when pane becomes visible
  Given a disconnection pane that is not visible
  When the pane becomes visible
  Then the scramble effect should start animating (refreshing every 0.75 seconds)

Scenario: Scramble animation stops when pane becomes hidden
  Given a disconnection pane with active scramble animation
  When the pane becomes hidden
  Then the scramble effect should stop animating

Scenario: Disconnection message is centered in the pane
  Given a visible disconnection pane
  When the pane is displayed
  Then the message "Connection to VNC server lost" should be visible and centered
```

### Implementation Requirements
- Create a dedicated `DisconnectionPane` class extending JavaFX Pane
- Define the pane layout in a simple FXML file with the main pane and centered message
- Implement animated scramble effect using JavaFX Timeline or AnimationTimer
- Animation should refresh with new random pixels every 0.75 seconds
- Animation should automatically start when the pane is enabled/visible and stop when disabled/hidden

### Design Notes
- The scramble effect should use a coarse grid of semi-random gray cells (similar to current implementation)
- The message should be displayed in white, bold font (28pt) in a double-bordered square
- The pane should cover the entire canvas area when visible
