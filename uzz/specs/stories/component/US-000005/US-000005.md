# User Stories for Domain: component

## [US-000005] Display Remote Cursor
**As a** Developer,
**I want** to display the remote cursor rendered by the VNC server,
**So that** users can see the cursor position on the remote desktop.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX cursor rendering, TigerVNC library

### Acceptance Criteria
```gherkin
Scenario: Display Remote Cursor
  Given a VNCViewerFX component with an active connection
  When the VNC server sends cursor updates (e.g. changing from waiting cursor to default cursor)
  Then the remote cursor should be displayed on the component

Scenario: Hide Local Cursor
  Given a VNCViewerFX component
  When the component is active
  Then the local cursor should be hidden to avoid confusion with the remote cursor
```
