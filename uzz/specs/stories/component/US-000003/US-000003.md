# User Stories for Domain: component

## [US-000003] Support VNC Protocol Settings
**As a** Developer,
**I want** to configure VNC protocol settings such as shared connection, desktop resize, and ZRLE encoding,
**So that** the VNC viewer behaves as expected for my use case.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: VNC protocol, TigerVNC library

### Acceptance Criteria
```gherkin
Scenario: Configure Shared Connection
  Given a VNCViewerFX component
  When I set the shared connection option to true
  Then the component should allow multiple viewers to connect to the same desktop

Scenario: Configure Desktop Resize
  Given a VNCViewerFX component
  When I enable desktop resize support
  Then the component should allow resizing the remote desktop dynamically
```
