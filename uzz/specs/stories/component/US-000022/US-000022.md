# User Stories for Domain: component

## [US-000022] Set retry timeout for automatic reconnection
**As a** Developer,
**I want** to set the retry timeout in the VNCViewer control
**So that** I can configure how long the component waits before attempting to reconnect after a connection loss

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX properties, FXML property support
* **Configuration**: this behaviour shall be configurable with a component property "reconnectTimeout"

### Acceptance Criteria
```gherkin
Scenario: Set reconnect timeout via Java API
  Given the component is created
  When calling viewer.setReconnectTimeout(Duration.ofSeconds(30))
  Then the component waits 30 seconds before retrying after a connection loss

Scenario: Set reconnect timeout via FXML
  Given the application @FXML contains <VNCViewer reconnectTimeout="30s"/>
  When showing the component
  Then the component waits 30 seconds before retrying after a connection loss

Scenario: Default reconnect timeout when not configured
  Given the component is created
  When no reconnect timeout is explicitly set
  Then the component uses the default reconnect timeout value

Scenario: Invalid reconnect timeout value
  Given the component is created
  When calling viewer.setReconnectTimeout(Duration.ofSeconds(-1))
  Then the component throws an IllegalArgumentException
```

### Implementation Requirements
- The component shall provide a setReconnectTimeout(Duration) method
- The component shall provide a reconnectTimeout(Duration) method as alias of setReconnectTimeout
- The component shall provide a getReconnectTimeout() method
- The component shall provide a reconnectTimeout() method as alias of getReconnectTimeout
- The component shall provide a reconnectTimeout JavaFX property
- The component shall support FXML attribute "reconnectTimeout" with duration string values
- The component shall enforce reconnectTimeout > 0 and throw IllegalArgumentException otherwise
- The default reconnect timeout value shall be defined by the component implementation
