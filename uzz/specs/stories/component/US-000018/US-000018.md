# User Stories for Domain: component

## [US-000018] Resize remote desktop on component resizing - configurable
**As a** Developer,
**I want** the VNCViewerFX component to optionally resize the remote desktop
accordingly to the component size.
**So that** users can control the remote desktop size from remote.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX UI feedback, FXML, JavaFX animations
* **Configuration**: this behaviour sshall be configurable with a component property
* **Dependencies**: The disconnection pane will be controlled by the `connected` BooleanProperty from VNCCanvas

### Acceptance Criteria
```gherkin
Scenario: Resize remote desktop
  Given the component is configured to resize the desktop
  When the pane is resized
  Then the remote desktop is resized accordingly (precisely, the VNC sever receives
  desktop resize message).

Scenario: Do not resize remote desktop
  Given the component is configured to NOT resize the desktop
  When the pane is resized
  Then the remote desktop size does not change (precisely, no desktop resize
  message is sent to the VNC server)
```
