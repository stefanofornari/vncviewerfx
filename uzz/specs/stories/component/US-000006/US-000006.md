# User Stories for Domain: component

## [US-000006] Support Desktop Resizing
**As a** Developer,
**I want** to dynamically resize the remote desktop displayed in the VNCViewerFX component,
**So that** users can adjust the viewing area as needed.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX layout management, TigerVNC library

### Acceptance Criteria
```gherkin
Scenario: Resize Remote Desktop
  Given a VNCViewerFX component with an active connection
  When I resize the component
  Then the remote desktop should adjust to fit the new dimensions

Scenario: Handle Invalid Resize Request
  Given a VNCViewerFX component with an active connection
  When I attempt to resize the component to invalid dimensions (e.g., 0x0)
  Then the resize request should be ignored, and the component should retain its current size
```
