# User Stories for Domain: component

## [US-000019] AUTO/MANUAL connection mode
**As a** Developer,
**I want** to be able to specify on the FXML descriptor if the connection shall
be start automatically or manually through its controller
**So that** I can control when to start the connection

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX UI feedback, FXML, JavaFX animations
* **Configuration**: this behaviour shall be configurable with a component property "connect"
with the following values:
- AUTO - the component starts the connection at controller's initialization time
- MANUAL - the component does not start the connection at initialization, it
  must be started calling `connect()` on the controller

### Acceptance Criteria
```gherkin
Scenario: Auto connect
  Given the component is configured to resize the desktop (connect="AUTO" in FXML)
  When the VCViewer is displayed
  Then the component establishes the connection and I see the content of the screen
  (or the disconnection screen)

Scenario: Manual start
  Given the component is configured with a value different than `AUTO` (e.g. connect="MANUAL" in FXML)
  When the VCViewer is displayed
  Then the component does not try to connect and shows the DisconnectPane screen
```

### Implementation Requirements
- FXML property: `connect` with values in ConnectionMode enum set to `AUTO', 'MANUAL'
