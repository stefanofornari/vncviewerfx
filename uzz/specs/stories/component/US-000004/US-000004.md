# User Stories for Domain: component

## [US-000004] Handle Mouse and Keyboard Input
**As a** Developer,
**I want** to capture and send mouse and keyboard input to the VNC server,
**So that** users can interact with the remote desktop.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX input events, TigerVNC library

### Acceptance Criteria
```gherkin
Scenario: Send Mouse Input to VNC Server
  Given a VNCViewerFX component with an active connection
  When I move the mouse, scroll the mouse wheel or click within the component
  Then the remote desktop should respond accordingly

Scenario: Send Keyboard Input to VNC Server
  Given a VNCViewerFX component with an active connection
  When I press a key on the keyboard
  Then the remote desktop should respond accordingly
```
