# User Stories for Domain: component

## [US-000021] Automatic reconnect
**As a** User,
**I want** that the component reconnects automatically if the connection is lost
  or could not be established, with the option of retrying immediately
**So that** I have to do nothing in case of temporarily disconnection

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX UI feedback, FXML, JavaFX animations

### Acceptance Criteria
```gherkin
Scenario: Using VNCViewer - connect
  Given the component is created, e.g. bound to a @FXML `viewer` of a controller)
  Given a VNC server is running on "localhost:5901"
  When calling viewer.connect("localhost", 5901)
  Then the component establishes the connection and I see the content of the screen

Scenario: Using VNCViewer - error
  Given the component is created, e.g. bound to a @FXML `viewer` of a controller)
  Given *NO* VNC server is running on "localhost:5901"
  When calling viewer.connect("localhost", 5901)
  Then the component shows the disconnection screen

Scenario: Using FXML - connect
  Given the application @FXML contains <VNCViewer uri="vnc://localhost:5901" connect="AUTO"/>
  Given a VNC server is running on "localhost:5901"
  When showing the component
  Then the component establishes the connection and I see the content of the screen

Scenario: Using FXML - error
  Given the application @FXML contains <VNCViewer uri="vnc://localhost:5901" connect="AUTO"/>
  Given *NO* VNC server is running on "localhost:5901"
  When showing the component
  Then the component shows the disconnection screen
```

### Implementation Requirements
- The component shall provide an onRetry() method to set the call back to be
  invoked when trying to re-connect
- The disconnection dialog shall provide a way (e.g. a button) to reconnect
  immediately
- When the disconnection dialog is visible, a countdown should be displayed starting
  at 10s; when the countdown reaches 0, the component retries to connect
