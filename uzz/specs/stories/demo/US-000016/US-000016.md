# User Stories for Domain: demo

## [US-000006] Demonstrate Cut & Paste Between Text Field and Canvas
**As a** Developer,
**I want** to demonstrate cut and paste functionality between a text field and the VNC canvas in the demo application,
**So that** users can see how clipboard synchronization works between the local and remote desktops.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX UI, TigerVNC library, Clipboard API

### Acceptance Criteria
```gherkin
Scenario: Copy Text from Text Field to Canvas
  Given the VNCViewerFX demo application with an active connection
  When I enter text into the text field and copy it
  Then the text should be pasted into the remote desktop via the VNC canvas

Scenario: Copy Text from Canvas to Text Field
  Given the VNCViewerFX demo application with an active connection
  When I copy text from the remote desktop via the VNC canvas
  Then the text should be pasted into the text field

Scenario: Handle Empty Clipboard
  Given the VNCViewerFX demo application with an active connection
  When I attempt to paste from an empty clipboard
  Then no action should occur, and no error should be displayed
```
