# User Stories for Domain: demo

## [US-000023] About Dialog
**As a** User,
**I want** see the following information in a About Dialog: application name,
  application version, short description, license
**So that** I can quickly refer to it

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX properties, FXML property support

### Acceptance Criteria
```gherkin
Scenario: Open the about dialog
  Given the demo application is visible
  When Clicking on the Hamburger Menu/About
  Then About Dialog display with the most updated:
  - application name
  - version
  - short description
  - license

Scenario: Close the about dialog
  Given the about dialog is visible
  When Clicking on button `Close`
  Then about dialog is closed
