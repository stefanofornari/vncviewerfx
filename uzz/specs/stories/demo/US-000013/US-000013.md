# User Stories for Domain: demo

## [US-000003] Display Options Dialog
**As a** Developer,
**I want** to display an options dialog in the demo application,
**So that** I can adjust settings such as encoding, compression, and display options.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX UI, TigerVNC library

### Acceptance Criteria
```gherkin
Scenario: Open Options Dialog
  Given the VNCViewerFX demo application
  When I open the options dialog
  Then the dialog should display all configurable settings

Scenario: Apply Settings from Options Dialog
  Given the VNCViewerFX demo application with the options dialog open
  When I change a setting and apply it
  Then the setting should be applied, and the VNC viewer should update accordingly
```
