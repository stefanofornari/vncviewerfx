# User Stories for Domain: demo

## [US-000004] Handle User Input in Demo
**As a** Developer,
**I want** to handle user input such as mouse and keyboard events in the demo application,
**So that** I can interact with the remote desktop.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX input events, TigerVNC library

### Acceptance Criteria
```gherkin
Scenario: Send Mouse Input
  Given the VNCViewerFX demo application with an active connection
  When I move the mouse or click within the demo window
  Then the input should be sent to the VNC server, and the remote desktop should respond accordingly

Scenario: Send Keyboard Input
  Given the VNCViewerFX demo application with an active connection
  When I press a key on the keyboard
  Then the input should be sent to the VNC server, and the remote desktop should respond accordingly
```
