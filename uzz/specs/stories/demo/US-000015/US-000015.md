# User Stories for Domain: demo

## [US-000005] Display Connection Status
**As a** Developer,
**I want** to display the connection status in the demo application,
**So that** I can monitor the state of the VNC connection.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX UI, TigerVNC library

### Acceptance Criteria
```gherkin
Scenario: Show Connected Status
  Given the VNCViewerFX demo application
  When the connection to the VNC server is established
  Then the connection status should be displayed as "Connected"

Scenario: Show Disconnected Status
  Given the VNCViewerFX demo application
  When the connection to the VNC server is lost
  Then the connection status should be displayed as "Disconnected"
```
