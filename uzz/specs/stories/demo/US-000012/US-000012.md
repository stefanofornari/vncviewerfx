# User Stories for Domain: demo

## [US-000012] Configure VNC Server in Demo
**As a** Developer,
**I want** to configure the VNC server settings in the demo application,
**So that** I can connect to different VNC servers for testing.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX UI, TigerVNC library

### Acceptance Criteria
```gherkin
Scenario: Configure VNC Server
  Given the VNCViewerFX demo application
  When I enter a valid VNC server address and port
  Then the application should connect to the server and display the remote desktop

Scenario: Handle Invalid Server Configuration
  Given the VNCViewerFX demo application
  When I enter an invalid VNC server address or port
  Then an error message should be displayed, and the connection should fail gracefully
```
